# Matter Fundamentals Course Exercises
This repository is part of the [Matter Fundamentals](https://academy.nordicsemi.com/courses/matter-fundamentals/) course by [Nordic Developer Academy](https://academy.nordicsemi.com).

The Matter Fundamentals course is a self-paced hands-on online course focusing on learning the essentials of Matter development using the highly extensible and feature-rich [nRF Connect SDK](https://www.nordicsemi.com/Products/Development-software/nrf-connect-sdk). 

This repository contains the exercise code base and solutions. Make sure to select the branch that corresponds with the nRF Connect SDK version of your choosing:
<ul>
    <li><code>main</code>: For nRF Connect SDK version v3.2.0 </li> 
</ul>
